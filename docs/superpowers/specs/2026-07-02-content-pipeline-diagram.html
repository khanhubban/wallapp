Content pipeline — publish-then-flip

Weekly drop = add images + metadata, run one command. Nothing live is ever mutated.

1 · Content workspace — private git repo (source of truth)

content/ ├── wallpapers/ │ ├── aurora-peak-001/ │ │ ├── master.png ← AI output OR licensed photo, high-res │ │ └── meta.yaml ← title · category · tags │ │ source: ai | photo-licensed | own ← mandatory │ │ license: …attribution/audit trail… ← mandatory │ │ tier: free | reward-unlock | plus-only │ └── city-rain-002/ … └── collections/ └── 2026-07-drop-01.yaml ← the weekly drop: ids, order, featured
▼ one command: ./gradlew :service:content-pipeline:publish

2 · Pipeline tool — new service/service-content-pipeline (Kotlin)

1

Validate

Schema-check every meta.yaml · masters exist · min resolution & aspect · license present

fails fast — nothing uploads
2

Render

Generate per-device renditions the app already expects (media-1a-c-p~uhd, ~s, tablet…) · v1 replicates demo format exactly; WebP/AVIF = phase 2

3

Build

Serialize catalog JSON using the app's own client models into a fresh api/YYYYMMDD/ dir

4

Publish

Upload complete version dir (staging first, then prod) · flip pointer last

atomic-ish · rollback = flip back
Pipeline serializes with shared/data/content-network models
=
App deserializes with the same Kotlin classes → format drift is a compile error, not a prod bug
▼ upload → then flip pointer

3 · Firebase Storage — versioned, immutable directories

key → api/20260625 ⟶ api/20260702 ← flipped only after upload completes
⟲ Rollback: point key back at api/20260625 — old version is still there, untouched.
▼ clients follow the pointer

4 · Clients — no live API server, just static downloads + cache

🤖 Android (Compose)

read key → fetch version JSON → download sized renditions → cache

🍎 iOS (SwiftUI)

same flow via shared KMP content-network code

AI generation stays outside the pipeline. Whatever generates images just deposits master.png + a meta.yaml stub into the workspace. Photos and AI art flow identically — the pipeline is source-agnostic.
