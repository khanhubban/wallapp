# Firestore Backend

This directory contains the code for the Firestore database in the project.

## Running Security Rules Tests

To run the security rules tests, you can use npm in the `test` directory. Follow these steps:

1. Navigate to the `test` directory within the `firebase-backend` directory.
2. Run the following command to install the required dependencies:
    ```
    npm install
    ```
3. Init and run the Firebase emulators.
4. Once the dependencies are installed, run the following command to execute the security rules tests:
    ```
    npm test
    ```
